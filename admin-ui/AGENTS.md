# Diretriz de produto

- Preserve a harmonia visual, os padrões de interação e a coerência entre telas.
- Se uma solicitação quebrar essa coerência ou prejudicar a usabilidade, avise o
  usuário antes de implementá-la e explique objetivamente o impacto.
- Proponha uma alternativa coerente; não execute silenciosamente uma decisão de
  design ruim apenas porque ela foi solicitada.
- Quando o usuário confirmar a escolha após conhecer o impacto, implemente-a,
  salvo quando houver impedimento técnico, de segurança ou acessibilidade.
